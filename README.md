# f-R-Cosmology---Hu-Sawicki-Model
This is code to solve the Modified Friedmann Equation if the Ricci Scalar representing curvature of space time is replaced by some function of the Ricci Scalar f(R) in the Einstein Field Equations, this gives us an alternate way to look at the universe without using the concept of dark energy.
Code involves solving the the complex set of non linear second order differential equations in R using the SciPy root solver and hence finding the non dimensionalized Hubble Constant
We then apply the log likelihood method to configure the best suited values of H(z), b, lambda and Omega_m0
